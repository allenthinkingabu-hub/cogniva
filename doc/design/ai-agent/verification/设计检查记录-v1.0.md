## 执行方法

使用隔离的临时Python环境安装jsonschema、PyYAML和openapi-spec-validator，运行本目录check_design.py。工具环境不属于应用运行版本。复现方式：

```sh
python3 -m venv /tmp/agent-design-check
/tmp/agent-design-check/bin/python -m pip install jsonschema==4.25.1 PyYAML==6.0.3 openapi-spec-validator==0.7.2
/tmp/agent-design-check/bin/python docs/design/ai-agent/verification/check_design.py
```

- Draft 2020-12 Schema结构、合法合成样例通过与非法样例拒绝。
