## 一、 核心内容极速透视（3 分钟掌握核心脉络）

### 1. 核心理论：大模型从“裸奔”走向“特权微内核隔离”
* **意图推导（Ring 3）**：大模型属于不可信外部协处理器，它输出的工具调用仅为“意图建议”，绝对不具备物理执行权；
* **Tools 执行（Ring 0）**：向外部划扣资金、修改数据库是产生不可逆物理副作用的敏感操作；
* **9 阶段门禁（AI Syscalls）**：Harness 在意图推导前后、工具执行前后、状态落盘前后切入 9 道系统调用门禁，构建闭环沙箱。

### 2. 真实业务落地：跨境电商“售后争议调解与退赔 Agent”
* 针对跨境逆向物流成本超过货值的痛点，让 Agent 自主执行“仅退款不退货”；
* 落地三道重锁：
  * **防提权**：在 `before_action` 剥离模型自填的 `permit=true`，由宿主签发带短期 STS 凭据的 `AuthorizedToolCall`；
  * **防重放**：在 `after_action` 绑定 SHA256 唯一幂等键 `operation_ref`，遭遇 Stripe 504 超时坚决不盲目重试，标为 `UNKNOWN` 挂起转入后台流水对账；
  * **防脑裂**：在 `before_checkpoint` 借由单调递增 `fencing_token` 与 CAS 锁，老 Worker 假死苏醒覆写时触发自杀，保障 12.6 万笔争议 0 资损、0 脏写。

### 3. 面试高频必杀点
* 面对网络超时绝不能回答“重试 3 次”（直接挂科！），必须回答“唯一幂等指纹 + 未知态挂起 + 独立对账补偿状态机”；
* 面对并发写冲突绝不能回答“简单加个分布式锁”，必须回答“单调递增 Fencing Token + 数据库 CAS 乐观锁 + 假死自杀模型”。
